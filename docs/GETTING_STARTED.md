# Начало работы с LeadGis

LeadGis собирает компании из 2GIS, проверяет сайты, готовит персональные сообщения и помогает вести статусы общения. Интерфейс работает в браузере, база данных хранится на вашем компьютере.

Это руководство также доступно в приложении: **«С чего начать»** в боковой панели (значок книги на телефоне).

## 1. Установка и запуск

Нужны Python 3.11 или новее, Node.js 18 или новее и npm. Выполняйте команды из корня скачанного репозитория. На Windows вместо `python3` используйте `py`, а для активации окружения — `.venv\Scripts\Activate.ps1` в PowerShell.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
cd frontend
npm install
npm run build
cd ..
leadgis start
```

Откроется **http://127.0.0.1:8000**. Если браузер не открылся автоматически, перейдите по адресу вручную. Оставьте терминал с сервером открытым. Для остановки нажмите `Ctrl+C`; для следующего запуска активируйте окружение и снова выполните `leadgis start`.

Для разработки установите `pip install -e ".[dev]"`. В отдельном терминале из `frontend/` можно запустить `npm run dev`; адрес напечатает Vite, запросы `/api` будут направлены на сервер на порту 8000.

## 2. Подключение 2GIS

1. Получите ключ с доступом к **Catalog API** в [кабинете разработчика 2GIS](https://dev.2gis.com/). Доступ и квоты зависят от условий вашего ключа.
2. Откройте **«Настройки» → «01 / Источник данных»**.
3. Вставьте ключ в **«API-ключ 2GIS»** и нажмите **«Проверить подключение»**.
4. При успешной проверке нажмите **«Сохранить»** внизу страницы.

Проверка использует введённый ключ, но сама его не сохраняет. Пустое поле при сохранении оставляет ранее заданный ключ. Ключи после сохранения не отображаются в интерфейсе.

## 3. Модель для сообщений и ваше предложение

Модель нужна для подготовки сообщений. Собирать и экспортировать контакты можно без работающей модели.

### Локальная модель через Ollama

Установите и запустите Ollama отдельно. Загрузите модель, которую хотите использовать, например:

```bash
ollama pull qwen2.5:14b
```

Эта модель может требовать значительных ресурсов компьютера; можно использовать другую установленную модель, указав её точное имя.

В **«Настройки» → «02 / Модель для сообщений»**:

- Выберите **«Ollama (локально)»**.
- Оставьте Base URL `http://localhost:11434/v1`.
- API-ключ для Ollama не нужен.
- Введите имя установленной модели или нажмите **«Список моделей»**.
- Нажмите **«Проверить подключение»**. Проверка делает короткий тестовый запрос к модели.

### Облачная модель

Выберите подходящего провайдера, укажите свой API-ключ и доступную вам модель. Можно использовать OpenAI-совместимый сервер с собственным Base URL. Провайдер может тарифицировать запросы; данные компании и текст предложения передаются выбранному провайдеру. При использовании Ollama обработка выполняется локально.

В **«03 / Ваше предложение»** заполните **«Ваша услуга»**, например:

> Делаем сайты для стоматологических клиник: онлайн-запись, услуги и цены. Запуск за две недели.

При необходимости добавьте инструкции: «Не больше трёх предложений, без ссылок, обращение на “вы”». Нажмите **«Сохранить»**.

## 4. Первая кампания

1. Перейдите в **«Кампании»**, нажмите **«Новая кампания»**.
2. Введите название: `Стоматологии · Алматы`.
3. Укажите нишу: `Стоматология`. Можно выбрать подсказку или ввести свой запрос.
4. Укажите город: `Алматы` и нажмите **«Создать кампанию»**.
5. В строке кампании нажмите **«Собрать лиды»**.

Сбор выполняется в фоне. Полоса над рабочей областью показывает текущую задачу и ошибки; её можно отменить. Статус кампании и количество лидов обновятся по завершении. Текущая версия запрашивает до 200 организаций за запуск; результат зависит от выдачи 2GIS и доступа вашего ключа. Повторный сбор не дублирует организации с тем же идентификатором внутри кампании.

## 5. Отбор и работа с лидами

Нажмите название кампании или стрелку в её строке. Также можно открыть **«Лиды»** и выбрать кампанию в списке.

Доступны поиск по названию, категории и адресу, фильтры по сайту, наличию телефона и статусу. Для продажи разработки сайтов начните с **«Нет сайта»** и **«С телефоном»**. Если результатов больше 50, используйте **«Назад»** и **«Далее»** под таблицей.

Статусы сайтов:

| Значение         | Что означает                                                   |
| ---------------- | -------------------------------------------------------------- |
| Нет сайта        | Сайт не указан или указана только социальная страница          |
| Есть сайт        | Сайт ответил на проверку                                       |
| Сайт не работает | Проверка получила ошибку соединения или HTTP                   |
| Не проверено     | Нет достоверного результата проверки, например из-за тайм-аута |

Нажмите название компании, чтобы открыть адрес, ссылки, редактор сообщения и выбор статуса. Сведения из каталога и результат проверки сайта стоит проверить перед обращением.

## 6. Сообщение и отправка

1. В раскрытой карточке нажмите **«Сгенерировать»**.
2. Дождитесь завершения задачи и прочитайте текст.
3. При необходимости исправьте текст и нажмите **«Сохранить»**. Кнопка WhatsApp доступна для сохранённого сообщения и лида с телефоном.
4. Нажмите **«Открыть WhatsApp»**. Откроется новая вкладка с предзаполненным сообщением. Разрешите всплывающие окна для локального адреса, если браузер блокирует вкладку.
5. Приложение предложит отметить лид как **«Отправлено»**. Подтверждайте этот статус, только если действительно отправляете сообщение; его можно изменить в карточке.
6. Отправьте сообщение самостоятельно в WhatsApp. Затем меняйте статус по мере общения: **«Ответили»**, **«Клиент»** или **«Отказ»**.

**«Сообщения для всей кампании»** запускает генерацию для всей выбранной кампании, независимо от фильтров и страницы таблицы. Это может заменить текущие сообщения. Используйте её осознанно; для отдельной компании доступна собственная кнопка генерации.

Наличие ссылки WhatsApp не подтверждает регистрацию номера. LeadGis не отправляет сообщения автоматически.

## 7. Экспорт

В разделе **«Кампании»** нажмите **CSV** или **XLSX** в строке кампании. Файл содержит все её лиды, контакты, статусы и текущие сообщения; фильтры в таблице лидов не ограничивают экспорт.

CSV подходит для импорта в CRM, XLSX — для электронных таблиц. Экспорт также доступен из терминала:

```bash
leadgis export 1 --format xlsx --output leads.xlsx
```

Замените `1` на ID кампании (он виден в адресе страницы её лидов: `/campaigns/1/leads`).

## Если что-то не работает

| Ситуация                          | Что сделать                                                                                  |
| --------------------------------- | -------------------------------------------------------------------------------------------- |
| Нет связи с сервером              | Проверьте, что терминал с `leadgis start` открыт; перезапустите сервер и нажмите «Повторить» |
| Не найден интерфейс               | Выполните `npm install` и `npm run build` в `frontend/`, затем перезапустите сервер          |
| Ошибка ключа 2GIS или лимита      | Проверьте сохранённый ключ, доступ к Catalog API и квоту; выполните проверку в «Настройках»  |
| Нет моделей в списке              | Проверьте Base URL, доступность провайдера и ключ; название модели можно ввести вручную      |
| Ollama не отвечает                | Запустите Ollama и проверьте, что модель загружена, а её имя совпадает с полем «Модель»      |
| Лиды есть, сообщение не создаётся | Проверьте модель, ключ и соединение в «Настройках», затем повторите генерацию для компании   |
| Нет результатов                   | Сбросьте фильтры; проверьте нишу и город кампании и запустите сбор                           |

## Данные и резервная копия

Конфигурация: `~/.leadgis/config.toml`. База данных: `~/.leadgis/leadgis.db`. Они создаются при первом запуске. Для резервной копии остановите сервер и скопируйте оба файла в безопасное место. Файл конфигурации содержит API-ключи — не публикуйте его.

В Docker данные находятся в томе `leadgis-data`; приведённые выше пути относятся к обычному локальному запуску.

## English quick walkthrough

1. Install Python 3.11+ and Node.js 18+, create a Python virtual environment, install with `pip install -e .`, then run `npm install` and `npm run build` inside `frontend/`. Run `leadgis start` from the repository root and open `http://127.0.0.1:8000`.
2. In **Настройки (Settings)**, enter a 2GIS Catalog API key, test the connection, and save.
3. Select an LLM provider and an installed/accessible model. Ollama uses `http://localhost:11434/v1` and needs no API key. Test the connection, describe your service in **Ваша услуга**, and save.
4. In **Кампании (Campaigns)**, create a campaign with a name, niche and city. Click **Собрать лиды (Collect leads)**.
5. Open the campaign's leads, filter them, and expand a company by clicking its name. Use **Сгенерировать (Generate)**, review the draft, and save any edits.
6. **Открыть WhatsApp (Open WhatsApp)** opens the saved message for manual sending. Update the lead's status after contact.
7. Download **CSV** or **XLSX** from the campaign row. Both exports include the entire campaign.

The built-in guide is available under **С чего начать**, or the book icon on mobile. Local data lives in `~/.leadgis/`. Cloud LLMs receive the data needed to generate messages; use Ollama for local model processing.
